# CareMitra – Healthcare Support Platform

## 📌 Project Overview

**CareMitra** is a healthcare support web application designed to connect patients and health workers through a simple, accessible, and user-friendly digital platform.

The application provides separate interfaces for:

* Patients
* Health Workers

The frontend demonstrates important healthcare services such as digital triage, appointments, medical records, referrals, follow-up alerts, emergency support, offline care, and health summaries.

This project is developed as a frontend prototype using React.js and mock data. It can later be connected to a backend, database, real-time services, and healthcare APIs.

## 🎯 Objectives

* Provide a simple healthcare support interface.
* Allow patients to access important healthcare services.
* Help health workers manage patient-related activities.
* Demonstrate digital triage and appointment management.
* Provide medical records and health summary screens.
* Support referral tracking and follow-up management.
* Include emergency SOS and emergency response interfaces.
* Provide offline-care interface support.
* Create a responsive and easy-to-use healthcare platform.

## 🔐 Login and Registration

The application provides two user roles:

### Patient

Patients can:

* Enter their name
* Enter a 10-digit phone number
* Create a secure password
* Access the Patient Dashboard

### Health Worker

Health workers can:

* Enter their name
* Enter a 10-digit phone number
* Select their worker type
* Create a secure password
* Access the Health Worker Dashboard

Available health worker types include:

* Community Health Worker
* ASHA Worker
* ANM
* Nurse
* Pharmacist
* Lab Technician
* Other

## 💾 Data Handling

* Mock data is used to demonstrate healthcare screens.
* LocalStorage is used for demo login information.
* No real patient medical information should be entered.
* No backend database is connected in the current version.
* The project can later be integrated with a secure backend and database.

## 🚨 Emergency Support

The application includes emergency-related interfaces such as:

* Emergency SOS
* Emergency Response
* Emergency Alert Centre

* High-Risk Patient Alerts
